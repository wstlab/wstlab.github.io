# 整理范围与验收

整理日期：2026-09-19。

## 来源与选择

以工作坊当前 `_门户` 注册的 60 个已提供双入口的案例及 `samples` 运行资源为基础。学科原始资料目录包含旧版本和未整合内容，不整体混入发布仓库。

| 内容 | 处理 |
| --- | --- |
| 当前 60 个案例与应用、大屏、多课时页面 | 保留到 projects |
| 当前门户、封面与分类 | 保留到 site |
| 第三方浏览器运行库 | 保留；有页面直接引用，不能当作 node_modules 删除 |
| PPTX 课件与素材平台空目录 | 排除 |
| deploy 下的历史发布包、备份、截图、运行日志 | 排除 |
| Python libs、本地后台数据库与教师登录信息 | 排除 |
| 原始分类目录、原始 source.html 备份 | 不纳入当前运行集合 |

原始工作坊目录未修改。本仓库不包含完整 QuickForm Flask 后台。

## 结构与修复

- 每项目新增 project.json，构建自动注册门户。
- 新增项目生成器、无 npm 运行依赖的构建 / 预览 / 校验脚本。
- 新增 GitHub Pages 自动检查发布工作流与 Dockerfile。
- 将站内路径转换为相对路径，支持根目录与项目子路径。
- 清理旧 HTML 中的跟踪像素、构建噪音和神经系统页面缺失的 page-auth.js 引用；这些公开案例没有因此获得真实身份验证。
- 默认本地数据适配，隔离旧任务服务；新增虚构文言名册。
- 保留媒体运行资源与第三方来源清单。

## 实际验证

- 构建注册 60 个项目。
- 138 个 HTML 页面、231 段内联 / 自有 JS 通过语法及本地资源路径检查。
- 4 个数据适配测试通过：本地写入读取、任务隔离、旧 Storage 命名空间兼容、远程任务映射、虚构名册（部分断言合并在同一测试）。
- Chromium 实际验证 `/QFDemo/` 门户显示 60 张卡片及搜索。
- 音频合成示例提交、IndexedDB 附件保存、导航到大屏后的音频恢复通过。
- 文言文序号进入通过；密铺案例提交与大屏读取通过。
- 上述核心浏览器流程未出现页面 JS 异常，未向外部服务发送 POST。
- 额外对全部 60 个项目的 index.html 与 dashboard.html 共 120 个入口进行 Chromium 首屏加载检查，未捕获页面 JS 异常。此项不覆盖延迟交互和所有外部请求的可用性。

这不表示 60 个案例的每种教学分支、硬件功能和外部资源均已逐一验收。远程自有 QuickForm 与 Docker 运行环境未在本次环境中实测。自动凭据模式检查也不等同于完整安全审计。
