QuickPrompt 是什么？一个帮你写出高质量 AI 提示词的工具。选择场景、填写需求，它帮你拼成结构完整的提示词。

两种模式：⚡ 快速模式一个完整提示词；🪜 脚手架模式分 5 个阶段（分析→方案→生成→调试→优化）。

提示词五要素：角色 / 任务 / 约束 / 格式 / 标准。所有生成的提示词都包含这五部分。

学科知识库：选择学科和年级后，自动匹配课本单元背景（前置知识、常见迷思、教学建议），让 AI 更懂你的教学场景。

API 注入：填入 QuickForm 地址和 DeepSeek Key 后，提示词中直接包含真实值，不需要搜索替换占位符。Key 仅用于生成提示词文本，不会上传。

安全提醒：生成的代码如果包含 API Key，请勿公开分享到互联网。
